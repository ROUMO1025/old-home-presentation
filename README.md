# Memories of an Old Home

Interactive proposal presentation for **SM5360 "Making" Interactive Things**.

**Pengran Chen · Mengyang Tang · Jingjun Jiang**  
Class presentation: 2 November 2026

A tabletop installation proposal in which one player tilts a radio-shaped handheld controller. The intended two-axis tray movement lets gravity roll a ball through a miniature old-home maze. Selected objects may respond with light, an opening route, or another interaction; these details remain subject to prototyping.

## View and edit

The presentation is a self-contained `index.html` with ten English slides, embedded assets, bilingual speaking notes and an illustrative tilt-and-ball demo. Open it in a modern browser, or use this repository's GitHub Pages site after deployment.

- **Arrow keys / Space:** move through slides.
- **F:** fullscreen.
- **N:** open the English–Chinese speaking notes for the current slide.
- **E:** edit the slide text in the browser.
- **Download HTML:** save a standalone copy, including your current text edits.
- **Slide 5:** watch the automatic motion demo or drag the radio to try the illustrated controls.
- **Slide 7:** open the proposed wiring diagram.
- **Slide 8:** open the complete materials list.

Browser edits are stored locally; download the HTML to keep or share an edited version.

The motion demo illustrates the proposed interaction. It does not represent completed hardware integration. Production details and team responsibilities are provisional.
